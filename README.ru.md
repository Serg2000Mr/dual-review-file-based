# Dual Review File Based

Два ИИ-агента итеративно ревьюируют планы и код, координируясь через обычные файлы, без серверов и оркестраторов.

## Зачем

ИИ-генерируемые планы и код выигрывают от второго мнения перед реализацией. Но настройка пайплайна ревью между агентами обычно требует MCP-серверов, оркестраторов или отдельной инфраструктуры. Этот скилл заменяет всё это простым файловым протоколом: агенты читают и пишут markdown-файлы в общем каталоге, каждый раунд порождая структурированное ревью с вердиктами и замечаниями, подкреплёнными доказательствами.

Роли не привязаны к приложениям: подходят Codex → Codex, Codex → ZCode, Claude Code → Codex и другие сочетания. Для ревью другой моделью выбирайте разные модели внутри этих приложений. Отдельный чат с той же моделью тоже поддерживается и даёт независимый контекст.

## Как это работает

Инициатор передаёт независимому агенту задачу и список файлов. Проверяющий изучает реальные файлы проекта и записывает структурированные замечания. Инициатор проверяет каждое замечание, вносит обоснованные исправления и открывает следующий раунд. Обновлённые файлы снова проходят проверку — до одобрения или достижения заданного числа раундов.

Состояние хранится в `.dual-review/` внутри проекта, поэтому сессию можно продолжить после перезапуска или прерывания. По умолчанию задание проверяющему передаётся вручную один раз; следующие раунды он подхватывает в той же сессии.

## Установка

Выберите комплект по приложению, в котором инициатор ведёт сессию. Не смешивайте файлы двух комплектов и завершите активные сессии перед обновлением установленной версии.

### Codex

Скопируйте содержимое каталога `codex/` в `.agents/skills/claude-dual-review-file-based/` вашего проекта:

```powershell
New-Item -ItemType Directory -Force .agents/skills/claude-dual-review-file-based
Copy-Item codex/* .agents/skills/claude-dual-review-file-based/ -Recurse -Force
```

Попросите Codex применить `$claude-dual-review-file-based` к задаче или плану. Передайте созданное задание выбранному проверяющему — например, другому чату Codex или ZCode.

### Claude Code

Скопируйте содержимое каталога `claude-code/` в `.claude/skills/codex-dual-review-file-based/` вашего проекта:

```bash
mkdir -p .claude/skills/codex-dual-review-file-based
cp claude-code/* .claude/skills/codex-dual-review-file-based/
```

Затем вызовите навык:

```text
/codex-dual-review-file-based <описание задачи> [путь/к/плану.md] [max_rounds=5]
```
